## Cómo ejecutarlo

Instala un JDK. Puedes abrir el código en IntelliJ IDEA, NetBeans o VS Code con soporte Java.

No se detectó un método `main`: esta carpeta contiene clases auxiliares o formularios. Requiere una aplicación que los invoque.
