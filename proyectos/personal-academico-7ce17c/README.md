# Personal académico

Clases para representar docentes y personal administrativo.

## Tecnologías

Java, Swing, concurrencia y programación orientada a objetos.

## Archivos disponibles

- [build.xml](build.xml)
- [src/Administrativo.java](src/Administrativo.java)
- [src/Docente.java](src/Docente.java)

## Cómo ejecutarlo

Instala un JDK. Puedes abrir el código en IntelliJ IDEA, NetBeans o VS Code con soporte Java.

No se detectó un método `main`: esta carpeta contiene clases auxiliares o formularios. Requiere una aplicación que los invoque.
